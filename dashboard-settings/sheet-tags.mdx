### What it does

As the number of sheets in your account grows, finding the right one gets harder. **Sheet Tags** let you attach short labels, such as `Customers`, `Finance` or `Staging`, to your sheets so you can group them and filter the Sheets page down to what you need.

Tags belong to your account and are shared with everyone on your team. A sheet can carry many tags, and a tag can be used on many sheets.

### How tags work

- **Account level:** Tags belong to one account, either a team or a personal account. They are never visible in another team or account.
- **Many to many:** One sheet can have several tags, and one tag can be on several sheets.
- **Names:** A tag name can be up to 100 characters. Names are trimmed, and they are unique in an account regardless of capital letters, so `Équipe` and `équipe` are the same tag. If you create a name that already exists, CSVBox uses the existing tag instead of making a duplicate.
- **Colors:** Every tag has a color from a fixed palette. A new tag automatically gets the color used the least in your account, so tags stay easy to tell apart. You can change the color at any time from the tag settings page.
- **Deleting a tag:** Removes the tag from every sheet it was on. The sheets themselves are not changed.

### Add tags to a sheet

1. Go to the **Sheets** page
2. Click **+ Tag** on the sheet you want to tag
3. In the picker, search for an existing tag and tick it to add it, or untick it to remove it
4. To create a new tag, type its name and press **Enter** or click **Create**

<Info>
  If the name you type is longer than 100 characters, the picker shows an error and the tag is not created.
</Info>

Each sheet row shows its first two tags as chips, followed by **+N more** if there are others. To remove a tag from a sheet, click the remove icon on its chip. Only that row updates.

### Filter sheets by tag

Use the filter dropdown on the **Sheets** page to narrow down the list.

- Tick one or more tags to see sheets that have **any** of the selected tags.
- The tag filter works together with the title search, so you can search within a tag.
- The selected tags are kept in the page address (for example `?tagFilter[0]=5`). The filter stays after a refresh, and you can share the link with a teammate who has access to the same account.

### Manage tags

Open the [Tags](https://app.csvbox.io/user/tags) page, or click a **Manage tags** link in the picker or filter, to manage all tags in one place.

From here you can:

- Create a tag
- Rename a tag
- Change the color of a tag
- Delete a tag
- See how many sheets each tag is used on
- Search and page through your tags

Anyone who can see the Sheets page can view tags and filter by them. See [Teams](/account/teams) for more about roles.

### Tags when you copy a sheet

| Copy type | What happens to tags |
| --- | --- |
| **Copy as new sheet** within the same account | The new sheet gets the same tags |
| **Copy as new sheet** to another team or account | No tags are copied, so your tag names never appear in another account |
| **Copy settings onto an existing sheet** | Tags are not touched. The target sheet keeps its own tags |

### Examples

| Goal | How to do it |
| --- | --- |
| Group sheets by customer | Create a tag per customer and tick it on each of their sheets. Filter by that tag to see them together |
| Separate environments | Tag sheets `Production` or `Staging`, and filter by one of them while testing |
| See several groups at once | Tick more than one tag in the filter. Sheets with any of them are shown |
| Share a view with a teammate | Apply your filter and copy the page address |

### Limitations

- Tag names are limited to 100 characters.
- Tags are not shared between teams or accounts, and they are not copied when a sheet is copied to another account.
- The filter shows sheets with **any** selected tag, not only sheets with all of them.
- Tags are used for organizing sheets in the dashboard. They are not part of the importer your end users see, and they are not sent to your destination with imported data.

### Troubleshooting

| What you see | Why | What to do |
| --- | --- | --- |
| No **+ Tag** option or remove icon | Your role cannot edit sheets | Ask a Super Admin, Admin or Tech user to make the change |
| No **Tags** page or **Manage tags** link | Your role does not have access to tag settings | Ask a Super Admin, Admin or Tech user |
| The tag picker says the name is too long | The name is over 100 characters | Use a shorter name |
| Creating a tag did not add a new one | A tag with the same name already exists, ignoring capital letters | Use the existing tag |
| A copied sheet has no tags | It was copied to another team or account, or onto an existing sheet | Add the tags again on the copied sheet |
| A shared filter link shows no tags selected | The tags belong to a different account than the one the person is using | Open the link in the same account |
