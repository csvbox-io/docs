---
title: "AI Bulk Transforms"
description: "Let users modify column data with natural language prompts directly in the importer."
---

AI Bulk Transforms let your users clean, format, and enrich entire columns with plain-language prompts during the **Verify Data** step of the import.

<Note>
  This feature is currently in beta.
</Note>

## How to enable AI transformations

<Steps>
  <Step title="Open the sheet settings">
    Go to your **Sheet Settings**.
  </Step>
  <Step title="Open the Verify Data tab">
    Click the **Import Steps** tab, then navigate to the **Verify Data** tab.
  </Step>
  <Step title="Turn on AI transformations">
    Set **Enable AI Transformations?** to **Yes**.
  </Step>
  <Step title="Save your settings">
    Save your settings.
  </Step>
</Steps>

Once enabled, a new **Bulk Transform** option appears for each column in the Verify step of the import flow.

## What can it do

Users can clean, format, and enrich their data using plain language. For example, they can:

* Capitalize or lowercase text in `'product_name'`
* Add a 10% markup to values in `'price'`
* Translate `'description'` to Spanish
* Format `'order_date'` to `YYYY-MM-DD`
* Extract the domain name from `'email'`
* Tag rows as `'Yes'` in `'priority'` if `'notes'` mentions "urgent"

These are just a few examples. The feature is flexible and handles a wide range of transformations across different languages.

## Key features

* Transform entire columns using simple AI prompts.
* User data never leaves the browser. Values are _not_ sent to any external AI models.
* Fix validation issues quickly by modifying problematic fields in bulk.
* Users can modify or delete rows, but can't add new rows using AI.
* Supports prompts in all languages available in the importer.
* Users can preview the data before applying changes.
