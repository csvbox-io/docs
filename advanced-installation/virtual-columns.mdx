**Virtual Columns** are one of CSVbox's most powerful data transformation tools. They run small snippets of JavaScript that **merge**, **split**, **re-format**, **correct**, and **enrich** incoming data during an import.

Use them to process your data, do calculations, or merge values together before the data reaches your end.

## How it works

<Steps>
  <Step title="Add a virtual column">
    For any sheet (template), add a virtual column in the CSVbox dashboard.
  </Step>
  <Step title="Attach a JavaScript snippet">
    Attach a JavaScript snippet to the virtual column.
  </Step>
  <Step title="Users submit the CSV file">
    After users submit the CSV file, the JavaScript runs to populate data in the virtual columns.
  </Step>
  <Step title="Data is pushed to the destination">
    Data from the uploaded CSV and the virtual columns is pushed to the data destination.
  </Step>
</Steps>

### Example

<Tabs>
  <Tab title="Merge">
    Merge data from the `first_name` and `last_name` columns into a new virtual column named `full_name`.

    Here is the JavaScript attached to the `full_name` virtual column:

    ```javascript
    try
    {
    	return csvbox.row["first_name"] + ' ' + csvbox.row["last_name"];
    }
    catch(err)
    {
      	return 'error: ' + err.name + ' | ' + err.message;
    }
    ```
  </Tab>
  <Tab title="Re-format">
    Normalize the incoming `order_date` into UTC format.

    ```javascript
    try
    {  	const date = new Date(csvbox.row["order_date"]);
    
    	return date.toUTCString();
    }
    catch(err)
    {
      	return 'error: ' + err.name + ' | ' + err.message;
    }
    ```
  </Tab>
  <Tab title="Static">
    Pass any static value to the virtual column.

    ```javascript
    try
    {
    	return 'Amazon';
    }
    catch(err)
    {
      	return 'error: ' + err.name + ' | ' + err.message;
    }
    ```
  </Tab>
</Tabs>

## Data rows

Data rows are the core object that virtual columns are built around. For each incoming CSV data row, you can read its data and manipulate it with JavaScript to populate the virtual column.

After the user submits the CSV, the JavaScript runs for each data row in sequential order to populate the virtual columns.

Use the `csvbox.row` object to work with each row, and `csvbox.row["column_name"]` to read a specific column of the data row. You can use data from a single column, multiple columns, or no columns to populate virtual columns.

## Inserting data into virtual columns

The value returned by the JavaScript snippet is added to the virtual column.

```javascript
// Extracting first name
try
{  	var fullName = csvbox.row["full_name"].split(' ');

	// retruning value
	return  fullName[0];
}
catch(err)
{
	//returning error
  	return 'error: ' + err.name + ' | ' + err.message;
}
```

<Note>
  If the JavaScript returns a `NULL` value, an empty string is added to the virtual column.
</Note>

## Dependencies

In the JavaScript snippet, you can use an external library hosted on a CDN. You can also call any external API endpoint to fetch real-time data. Add the library script tag and any custom scripts to the **Dependencies** section, then use them in the main JavaScript snippet.

For each import, the dependent scripts run only once, whereas the main JavaScript snippet runs once for each row.

<Accordion title="Example">
  Suppose you want to use the data from the incoming `USD_amount` column to create a new `GBP_amount` virtual column. The amount should be converted from USD to GBP using real-time exchange rates.

  You can use the [Money.js](https://github.com/openexchangerates/money.js) library for currency conversions and [Open Exchange Rates](https://openexchangerates.org/) to fetch real-time conversion rates. Here is the sample dependency code:

  ```javascript Dependent Scripts
  //Load jQuery via CDN
  <script src="https://code.jquery.com/jquery-3.6.1.min.js" integrity="sha256-o88AwQnZB+VDvE9tvIXrMQaPlFFSUTR+nldQm1LuPXQ=" crossorigin="anonymous"> </script>
  
  //Load Money.js via CDN
  <script src="https://cdnjs.cloudflare.com/ajax/libs/money.js/0.0.1/money.min.js" integrity="sha512-dfZQaBBlTXvL+AUQKi7dd/9kb/KhreymnZYVdinjigqTdZUrAnLUNJRV34DUPFCdyek9mMBns3rzTlipnBKhTg==" crossorigin="anonymous" referrerpolicy="no-referrer"> </script>
  
  //Fetch real-time conversion rates via ajax call and initialize fx object
  <script type="text/javascript" >
  
      // Load exchange rates data via AJAX:
      $.getJSON(
          // NB: using Open Exchange Rates here, but you can use any source!
          'https://openexchangerates.org/api/latest.json?app_id=fa4744d77e844adb9cc3533b7ae162f3',
          function(data) {
              // Check money.js has finished loading:
              if (typeof fx !== "undefined" && fx.rates) {
                  fx.rates = data.rates;
                  fx.base = data.base;
              } else {
                  // If not, apply to fxSetup global:
                  var fxSetup = {
                      rates: data.rates,
                      base: data.base
                  }
              }
          }
      );
  </script>
  ```

  Corresponding JavaScript snippet for the `GBP_amount` virtual column:

  ```javascript Javascript snippet
  try
  {
  	//USD to GBP
  	return fx.convert(csvbox.row["USD_amount"], {from: "USD", to: "GBP"});
  
  }
  catch(err)
  {
  	//returning error
    	return 'error: ' + err.name + ' | ' + err.message;
  }
  ```
</Accordion>

## Variables

In the virtual column JavaScript snippet, you have access to data variables in the `csvbox` object. The following data is available:

<a id="csvboxrow" />

### `csvbox.row`

Contains the row data. Access each cell in the row by providing the column name. Examples:

```javascript
csvbox.row["first_name"]
csvbox.row["order_id"]
csvbox.row["price"]
```

<Warning>
  The column name must exist on the sheet, or an error is thrown.
</Warning>

### `csvbox.user`

Contains the [custom user attributes](/getting-started/2-install-code#referencing-the-user) defined while initializing the importer. Examples:

```javascript
csvbox.user["user_id"]
csvbox.user["team_id"]
csvbox.user["isAuthenticated"]
```

### `csvbox.import`

Contains data specific to the current import. The following data is available:

```javascript
csvbox.import["sheet_id"]
csvbox.import["sheet_name"]
csvbox.import["original_filename"]
csvbox.import["import_start_time"]
csvbox.import["destination_type"]
csvbox.import["total_rows"]
csvbox.import["row_number"] //current row number starting with 1
```

<a id="csvboxvirtual" />

### `csvbox.virtual`

Contains data from the preceding virtual columns.

```javascript
csvbox.virtual["final_name"]
csvbox.virtual["age"]
```

<Warning>
  Only data from the virtual columns defined before the current virtual column is available for use.
</Warning>

<a id="csvboxenvironment" />

### `csvbox.environment`

Contains the [environment variables](/advanced-installation/environment-variables) passed during importer initialization.

```javascript
// Example Usage
if(csvbox.environment["user_id"] && csvbox.environment["user_id"] == "abc123") {

 // code

}
```

<Tip>
  Use `console.log(csvbox);` to print all the available variables in the debugging console.
</Tip>
