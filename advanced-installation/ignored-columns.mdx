---
title: "Ignored Columns"
description: "Let users drop selected columns from the import process."
---

Users sometimes want to skip a column during data submission. This is especially useful when you use the importer to update existing data: to avoid overwriting existing columns, users can mark those columns as **Ignored** and the importer skips them. With CSVbox, you can give users the option to mark certain columns as ignored.

## Enabling ignored columns

First, activate the Ignore Columns option in your CSVbox dashboard.

<Steps>
  <Step title="Log in to your account">
    Sign in to the CSVbox dashboard.
  </Step>
  <Step title="Edit the sheet">
    Open the sheet of your choice for editing.
  </Step>
  <Step title="Open the Options tab">
    Go to the **Options** tab.
  </Step>
  <Step title="Allow columns to be ignored">
    Select **Yes** for the **Allow Columns to be Ignored** field.
  </Step>
  <Step title="Save the sheet">
    Click **Save**.
  </Step>
</Steps>

The importer then shows the option to mark columns as ignored on the Column Mapping screen.

Columns marked as ignored aren't visible on the Verify Data screen.

<Note>
  The Ignore Column option isn't available for columns marked as **Required**.
</Note>

### Default selection

When the **Default Selection** option is set to **Yes**, all unmapped columns default to Ignore Column.

## Data from ignored columns

Ignored columns aren't pushed to any destination. Only the metadata (the list of ignored columns) is pushed to the following destinations:

- [API/Webhook](/destinations#api--webhook)
- [Zapier](/destinations/zapier)
- [Client Side](/getting-started/3-receive-data#data-on-the-client-side)

### Ignored column list

In the API response JSON object, the list of ignored columns appears inside the `ignored_columns` object, as shown below. The `ignored_columns` object is visible only if ignored columns are activated. In the example below, check lines 16 and 36.
