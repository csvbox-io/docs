Programmatically create and manage CSVBox sheets and their column configurations directly through the API, instead of only through the dashboard.

### Authentication

All Sheet API requests require both of these headers. You can find the keys on the **API Keys** page of the CSVBox dashboard. More details are on the [Auth API](/advanced-installation/auth-api) page.

| Header | Value |
| --- | --- |
| `x-csvbox-api-key` | Your API key |
| `x-csvbox-secret-api-key` | Your secret API key |

<Warning>
  Never expose your secret key in browser-side code. Call the Sheet API from your backend.
</Warning>
