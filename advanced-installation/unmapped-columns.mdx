---
title: "Unmapped Columns"
description: "Allow users to submit columns not included in the sheet template."
---

Sometimes each of your users has unique columns in their sheets that they want to upload. You don't know these columns beforehand, so you can't configure them as part of the sheet template. They can be discovered only after the user uploads the file, so you can't configure them as [dynamic columns](/advanced-installation/dynamic-columns#basic-installation) either. CSVbox calls these columns **Unmapped Columns**, and you can choose to accept them.

## Enabling unmapped columns

Start accepting data from unmapped columns by activating the option in your CSVbox dashboard.

<Steps>
  <Step title="Log in to your account">
    Sign in to the CSVbox dashboard.
  </Step>
  <Step title="Edit the sheet">
    Open the sheet of your choice for editing.
  </Step>
  <Step title="Open the Options tab">
    Go to the **Options** tab.
  </Step>
  <Step title="Accept unmapped columns">
    Select **Yes** for the **Accept Unmapped Columns?** field.
  </Step>
  <Step title="Save the sheet">
    Click **Save**.
  </Step>
</Steps>

The importer then starts accepting data from the unmapped columns that users submit.

## Receiving data from unmapped columns

Data from unmapped columns is available in the data destinations along with the data from the regular columns. Currently, unmapped columns are supported only by the following destinations:

- [API/Webhook](/destinations#api--webhook)
- [Amazon S3](/destinations#amazon-s3)

### API/Webhook data destination

In the API response JSON object, the dynamic data appears inside the `_unmapped_data` object, as shown below. The `_unmapped_data` object is visible only if unmapped columns are activated. In the example below, check lines 12 and 32.

```json
[
  {
    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 1,
    "row_data": {
          "Name": "TP-Link TL-WN822N Wireless N300 High Gain USB Adapter",
          "SKU": "AS-100221",
          "Price": "33.00",
          "Quantity": "3",
          "_unmapped_data":{
		"Barcode": "7832748937489",
		"_empty_header_1": "TP-Link",
		"Tags": "electronics, networking"
           }
    },
    "custom_fields": {
      "user_id": "1002"
    }
  },
  {
    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 2,
    "row_data":{
          "Name": "EPower Technology EP-600PM Power Supply 600W ATX12V 2.3 Single 120mm Cooling Fan Bare",
          "SKU": "AS-103824",
          "Price": "95.35",
          "Quantity": "8",
           "_unmapped_data":{
		"Barcode": "4532748937411",
		"_empty_header_1": "EPower",
		"Tags": ""
           }
        },
    "custom_fields": {
      "user_id": "1002"
    }
  },
]
```

<Note>
  If any unmapped column has no header in the user's uploaded file, the app auto-inserts the column names `_empty_header_1`, `_empty_header_2`, and so on.
</Note>

### S3 data destination

In the AWS S3 file store, unmapped columns are added as new columns in the uploaded file.
