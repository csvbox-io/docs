---
title: "Dynamic Columns"
description: "Add new columns to the sheet at run time through the installation code."
---

Sometimes you can't use a fixed template to collect data, because the columns in the data model depend on the end user's preferences or other criteria. For these cases, CSVbox lets you add unique **dynamic columns** to each import at run time.

## Basic installation

Configure dynamic columns in the installation code. Here's a basic configuration that adds 2 dynamic columns, `qualification` and `experience`.

<Tabs>
  <Tab title="Javascript">
    Pass the dynamic columns you want to add as an array input parameter to the `setDynamicColumns()` method while initializing the importer.

    ```javascript
    importer.setDynamicColumns([
             {
              "column_name" : "qualification"
             },
             {
              "column_name": "experience"
              }
    ])
    ```

    Basic installation steps are available [here](/getting-started/2-install-code).
  </Tab>
  <Tab title="React">
    Pass the dynamic columns as an object to the `dynamicColumns` property of the `CSVBoxButton` component.

    ```javascript
      dynamicColumns={[
                   {
                     "column_name" : "qualification"
                   },
                   {
                      "column_name": "experience"
                  }
      ]}
    ```

    Basic installation steps are available [here](/getting-started/2-install-code).
  </Tab>
  <Tab title="Angular">
    Add `[dynamicColumns]="dynamicColumns"` to the existing template.

    ```typescript
    @Component({
      selector: 'app-root',
      template: `
        <csvbox-button
          [licenseKey]="licenseKey"
          [user]="user"
          [dynamicColumns]="dynamicColumns"
          [imported]="imported.bind(this)">
          Import
        </csvbox-button>
      `
    })
    ```

    Then pass the dynamic columns as an object to the `dynamicColumns` property of the AppComponent. Example:

    ```javascript
      dynamicColumns=[
                   {
                     column_name : "qualification"
                   },
                   {
                      column_name: "experience"
                  }
      ]
    ```

    Basic installation steps are available [here](/getting-started/2-install-code).
  </Tab>
  <Tab title="Vuejs">
    Add `:dynamicColumns="dynamicColumns"` to the existing template.

    ```html
    <template>
      <div id="app">
        <CSVBoxButton
          :licenseKey="licenseKey"
          :user="user"
          :dynamicColumns="dynamicColumns"
          :onImport="onImport">
          Upload File
        </CSVBoxButton>
      </div>
    </template>
    ```

    Pass the dynamic columns as an object to the `dynamicColumns` property of the `CSVBoxButton` component. Example:

    ```javascript
      dynamicColumns: [
                   {
                     column_name : "qualification"
                   },
                   {
                      column_name: "experience"
                  }
      ]
    ```

    Basic installation steps are available [here](/getting-started/2-install-code).
  </Tab>
</Tabs>

Dynamic columns are visible in the importer along with the other regular columns.

## Advanced configuration

    ```javascript
              "type": "text",
              "validators":
    ```

  `column_name` is the only mandatory key for adding a dynamic column.

### Configuration options

| Key | Description |
| --- | --- |
| [column_name](/dashboard-settings/sheet-options#column-name) \* | The column name that is pushed to the data destination. |
| [display_label](/dashboard-settings/sheet-options#display-label) | The user-friendly column label that users see in the importer. |
| [info_hint](/dashboard-settings/sheet-options#info-hint) | Help tooltips displayed when users hover the mouse over the Display Label (or click it) in the importer. |
| [matching_keywords](/dashboard-settings/sheet-options#matching-keywords) | Comma-separated set of keywords used as alternative matching options to help users match column names automatically. |
| [type](/dashboard-settings/sheet-options#column-type) | The data type of the incoming data. Possible values are: **text**, **number**, **email**, **date**, **boolean**, **regex**, **ip**, **url**, **credit_card**, **phone_number**, **currency**, **list**, **dependent_list**, **dynamic_list**, **dependent_dynamic_list**, **multiselect_list**, and **multiselect_dynamic_list**. |
| [validators](/advanced-installation/dynamic-columns#validator-options) | The validation rules for the data, based on the column type. Validator options are listed below. |
| [default_value](/dashboard-settings/sheet-options#default-value) | A default filler value for the column in case the incoming data is blank. |
| [required](/dashboard-settings/sheet-options#required) | Indicates whether a column is mandatory. |
| [position](/advanced-installation/dynamic-columns#column-position) | The display index of the column. Starts from 1. |
| [read_only](/dashboard-settings/sheet-options#read-only) | If set to **true**, users can't edit the data in this column. The default value is **false**. |

### Column position

By default, dynamic columns are displayed after the regular columns.

The `position` parameter re-orders the dynamic columns so they display before or in between the regular columns.

The `position` value starts from 1, which indicates the first position in the final column list. It is an optional parameter when defining dynamic columns.

## Receiving dynamic data

Data from dynamic columns is available in the data destinations along with the data from the regular columns. Currently, dynamic columns are supported only by the following destinations:

- [None](/destinations#none)
- [API/Webhook](/destinations#api--webhook)
- [Test API](/destinations#test-api)
- [Amazon S3](/destinations#amazon-s3)

### API/Webhook data destination

In the API response JSON object, the dynamic data appears inside the `_dynamic_data` object, as shown below. The `_dynamic_data` object is visible only if dynamic columns are configured for the import. In the example below, check lines 12 and 31.

```json

    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 1,
    "row_data": {

          "SKU": "AS-100221",

		"qualification": "MBA",
```

### S3 data destination

In the AWS S3 file store, dynamic columns are added as new columns in the uploaded file.
