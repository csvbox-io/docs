Templates (or sheets) define the structure of the data that you want to accept from your users.

## Create a sheet

<Steps>
  <Step title="Add a sheet">
    Go to the **Sheets** page in your dashboard and add a sheet.
  </Step>
  <Step title="Specify columns">
    Add the columns you want to accept, then configure the validation rules and data format for each column.

    <Note>
      When users upload a file, the importer validates the data in every column and tells them about any errors. Users must resolve the errors before they can submit the file.
    </Note>
  </Step>
  <Step title="Configure the destination">
    On the **Data Destination** tab, configure where you want the data to be pushed. The destination can be an API endpoint, an Amazon S3 bucket, a MySQL database, or any of the other [destinations](/destinations).
  </Step>
</Steps>
