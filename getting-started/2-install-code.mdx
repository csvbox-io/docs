Embed the CSVbox importer in your app with a short code snippet. Go to the **Code** tab of the sheet, find the integration code, and place it in your application where you want the import button to appear.

## Install the importer

<Tabs>
  <Tab title="JavaScript">
    Sample code with basic usage:

    ```javascript
    <button class="btn btn-primary" data-csvbox disabled onclick="importer.openModal();">Import</button>
    <script type="text/javascript" src="https://js.csvbox.io/script.js"></script>
    <script type="text/javascript">
        function callback(result, data) {
            if(result){
                console.log("success");
                console.log(data.row_success + " rows uploaded");
                //custom code
            }else{
                console.log("fail");
                //custom code
            }
        }
        let importer = new CSVBoxImporter("YOUR_LICENSE_KEY_HERE",{
        }, callback);
    
        importer.setUser({
            user_id: "default123"
        })
    </script>
    ```

    <Note>
      Each sheet has a unique license key. Find it on the **Code** tab of the sheet page and pass it to the `CSVBoxImporter` function.
    </Note>
  </Tab>
  <Tab title="React">

    ```javascript
    npm install @csvbox/react
    ```

    ```javascript

              return <button disabled={isLoading} onClick={launch}>Upload file</button>;
    ```

    <Note>


## Callback function

Once the user uploads a file, the importer returns the status of the import along with metadata describing the completed import. Data is returned in two variables, `result` and `data`:

- **`result`**: a boolean that is `true` if the import succeeds and `false` if it fails.
- **`data`**: JSON data as shown below.

```javascript
  {
    "import_id": 79418895,
    "sheet_id": 575,
    "sheet_name": "Products Import",
    "destination_type": "webhook"
    "row_count": 100,
    "row_success": 98,
    "row_fail": 2,
    "import_status": "Partial",
    "import_starttime": 87987897897,
    "import_endtime": 90890890809,
    "original_filename": "example-1.csv",
    "raw_file": "https://file-download-link",
    "custom_fields": {
      "user_id": "Z1001"
    },
    "column_mappings": [
      { "Name": "Name" },
      { "SKU": "Product SKU" },
      { "Price": "Sale Price" },
      { "Quantity": "Inventory"},
      { "Image URL": "Img"}
    ]
  }
```

<Note>
  The `data` object is null if the import fails. You can also configure the importer to receive the entire file data in JSON format in the `data` object. [Learn more](/getting-started/3-receive-data#data-on-the-client-side).
</Note>

You can write custom code to handle the success or failure conditions on the client side.

## Options

These additional configuration options are available with the CSVbox importer.

### max_rows

- **Type**: `number`
- **Default**: `null`

Specify the maximum number of rows that a single file can import. This value excludes the file headers. If a sheet has 101 rows and the first row is the header, the file is considered to have 100 data rows.

### max_rows_allow_submit

- **Type**: `boolean`
- **Default**: `true`

Allow or disallow submitting the permissible number of rows when the overall row count exceeds the limit. For example, suppose the row limit (`max_rows`) is set to 5:

- If `max_rows_allow_submit` is `true`, the user can upload the top 5 rows of their file.
- If `max_rows_allow_submit` is `false`, the user can't submit even 1 row if the overall row count exceeds `max_rows`.

### max_rows_custom_message

- **Type**: `string`
- **Default**: `null`

Display a custom message to the user when the file row count is greater than `max_rows`. This message shows only when `max_rows_allow_submit` is set to `false`.

### min_rows

- **Type**: `number`
- **Default**: `null`

The minimum number of rows required for a single upload.

### min_rows_custom_message

- **Type**: `string`
- **Default**: `null`

Display a custom message when the file row count is less than `min_rows`.

### language

- **Type**: `string`
- **Default**: `null`

Specify the importer frontend language. This value overrides the default language configured in the CSVbox dashboard. Acceptable values:

| Value | Language |
| --- | --- |
| `en` | English |
| `de` | German |
| `fr` | French |
| `es` | Spanish |
| `nl` | Dutch |
| `pt` | Portuguese |
| `th` | Thai |
| `pl` | Polish |
| `ro` | Romanian |
| `he` | Hebrew |
| `ja` | Japanese |
| `da` | Danish |
| `tr` | Turkish |
| `sk` | Slovak |
| `hi` | Hindi |
| `ms` | Bahasa Malaysia (Malay) |
| `ru` | Russian |
| `vi` | Vietnamese |
| `ko` | Korean |
| `id` | Bahasa Indonesia |
| `ar-EG` | Egyptian Arabic |
| `ur` | Urdu |
| `zh-CN` | Chinese (Simplified) |
| `zh-TW` | Chinese (Traditional) |
| `bg` | Bulgarian |
| `cs` | Czech |
| `hu` | Hungarian |
| `uk` | Ukrainian |

### allow_invalid

- **Type**: `boolean`
- **Default**: `0`

Specifies whether users can continue to submit the file even if there are validation errors.

### request_headers

- **Type**: `{ key: value, key: value, ... }`
- **Default**: `null`

Defines additional headers that are passed with each HTTP request.

### dynamic_list_request_headers

- **Type**: `{ key: value, key: value, ... }`
- **Default**: `null`

Defines additional headers that are passed with each HTTP request for the [dynamic list API](/dashboard-settings/validations#dynamic-list).

### sample_template_url

- **Type**: `String`
- **Default**: `null`

The URL from which end users download the sample CSV file.

### sample_template_button_text

- **Type**: `String`
- **Default**: `null`

The text on the button for downloading the sample CSV file.

<Note>
  Use the `sample_template_url` and `sample_template_button_text` options together to give end users a customized, dynamic sample CSV file.
</Note>

### target_file_name

- **Type**: `String`
- **Default**: `null`

Specifies the name of the file that is pushed to your destination. This applies only to the following destinations:

- S3
- FTP Server
- Google Sheets

### upload_file_url

- **Type**: `String`
- **Default**: `null`

The URL of the file to import. Use it when you want the data preloaded into the importer without asking users to upload a file. Provide the file location, and the importer loads the data when the user clicks the **Import** button.

### upload_file_worksheet_name

- **Type**: `String`
- **Default**: `null`

The name of the worksheet to upload when you upload a file with multiple tabs through the [`upload_file_url`](/getting-started/2-install-code#upload_file_url) option.

### theme

- **Type**: `String`
- **Default**: `null`

Initializes the importer with the specified theme. Supported values: `light`, `light-custom`, `dark`, `dark-custom`. If not specified, the theme set in the sheet dashboard is used by default.

### default_header_row

- **Type**: `number`
- **Default**: `1`

The row to auto-select as the header on the **Header Selection** page. Rows are 1-indexed.

## Events

These additional importer events and properties are available.

### onReady

Triggers when the importer is initialized and ready for use. Users can then click the **Import** button to open the importer modal dialog.

### onLoadStart

Triggers when the importer iframe starts loading.

<Note>
  In vanilla JavaScript, `onLoadStart` triggers only when [Lazy Load](/getting-started/2-install-code#lazy-load) is activated. Without Lazy Load, the iframe starts loading as soon as the importer is initialized.
</Note>

### onClose

Triggers when the importer is closed.

### onSubmit

Triggers when the user clicks **Submit** to upload the validated file. The `data` object is available in this event and contains metadata about the import.

<Accordion title="onSubmit data object sample">
  ```json
  {
    "import_id": 79418895,
    "sheet_id": 575,
    "sheet_name": "Products Import",
    "destination_type": "webhook",
    "row_count": 100,
    "import_starttime": 87987897897,
    "original_filename": "example-01.csv",
    "custom_fields": {
      "user_id": "Z1001"
    },
    "column_mappings": [
      {
        "Item": "Product Name"
      },
      {
        "SKU": "Product SKU"
      },
      {
        "Price": "Sale Price"
      },
      {
        "Quantity": "Inventory"
      },
      {
        "Image URL": "Img"
      }
    ]
  }
  ```
</Accordion>

### onImport

Triggers when all the data is pushed to the destination. Two objects are available in this event:

- **`result`** (boolean): `true` when the import succeeds and `false` when it fails.
- **`data`** (object): contains metadata about the import.

## Other settings

### Lazy load

The importer assets load when the webpage loads. This can slow your app if you initialize multiple importers on the same page. As a workaround, defer loading the importer assets until the **Import** button is clicked by adding the `lazy: true` parameter to the initialization code.

<Tabs>
  <Tab title="JavaScript">
    ```javascript
    let importer = new CSVBoxImporter("YOUR_LICENSE_KEY_HERE",{
        }, callback, { lazy: true });
    
    ```
  </Tab>
  <Tab title="React">
    ```javascript
    import { CSVBoxButton } from '@csvbox/react'
    import './App.css';

      return (
        <div className="App">
          <CSVBoxButton
            licenseKey="YOUR_LICENSE_KEY_HERE"
            user={{
              user_id: "default123"

              if(result){
                console.log("success");
                console.log(data.row_success + " rows uploaded");

                console.log("fail");
                //custom code
              }
            }}

          >
            Import
    ```
