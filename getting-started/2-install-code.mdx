Embed the CSVbox importer in your app with a short code snippet. Go to the **Code** tab of the sheet, find the integration code, and place it in your application where you want the import button to appear.

## Install the importer

<Tabs>
  <Tab title="JavaScript">
    Sample code with basic usage:

    ```javascript
    <button class="btn btn-primary" data-csvbox disabled onclick="importer.openModal();">Import</button>
    <script type="text/javascript" src="https://js.csvbox.io/script.js"></script>
    <script type="text/javascript">
        function callback(result, data) {
            if(result){
                console.log("success");
                console.log(data.row_success + " rows uploaded");
                //custom code
            }else{
                console.log("fail");
                //custom code
            }
        }
        let importer = new CSVBoxImporter("YOUR_LICENSE_KEY_HERE",{
        }, callback);
    
        importer.setUser({
            user_id: "default123"
        })
    </script>
    ```

    <Note>
      Each sheet has a unique license key. Find it on the **Code** tab of the sheet page and pass it to the `CSVBoxImporter` function.
    </Note>
  </Tab>
  <Tab title="React">
    Install using npm:

    ```javascript
    npm install @csvbox/react
    ```

    This gives you access to the `CSVBoxButton` component, which has the basic functionality of the importer. Import the `CSVBoxButton` component into your project.

    ```javascript
    import { CSVBoxButton } from '@csvbox/react'
    ```

    Basic usage:

    ```javascript
    <CSVBoxButton
      licenseKey="YOUR_LICENSE_KEY_HERE"
      user={{
        user_id: "default123"
      }}
      onImport={(result, data) => {
        if(result){
          console.log("success");
          console.log(data.row_success + " rows uploaded");
          //custom code
        }else{
          console.log("fail");
          //custom code
        }
      }}
      render={(launch, isLoading)=>{
              return <button disabled={isLoading} onClick={launch}>Upload file</button>;
          }}
    >
      Import
    </CSVBoxButton>
    ```

    <Note>
      Each sheet has a unique license key. Find it in the **Code** section of the sheet page and attach it to the `licenseKey` property of the `CSVBoxButton` component.

      The optional `render` property lets you pass in your own button to use in place of the standard CSVbox element.
    </Note>
  </Tab>
  <Tab title="Angular">
    Install using npm:

    ```javascript
    npm install @csvbox/angular
    ```

    <Note>

    **Import**

    Add `CSVBoxAngularModule` to your module imports.

    ```javascript
    import { CSVBoxAngularModule } from "@csvbox/angular";
    
    @NgModule({
      ...
      imports: [
        ...
        CSVBoxAngularModule
      ]
    ```

    Once this is set up, you can import and access the `CSVBoxMethods` module in your app component file.

    It brings the `csvbox-button` component into your project. Example:

    ```text
    <csvbox-button [licenseKey]="licenseKey" [imported]="imported.bind(this)" [user]="user">Import</csvbox-button>
    ```

    Basic usage:

    ```javascript
    @Component({
      selector: 'app-root',
      template: `
        <csvbox-button
          [licenseKey]="licenseKey"
          [user]="user"
          [imported]="imported.bind(this)">
          Import
        </csvbox-button>
      `
    })
    
    export class AppComponent {
    
      title = 'example';
      licenseKey = 'YOUR_LICENSE_KEY_HERE';
      user = { user_id: 'default123' };
    
      imported(result: boolean, data: any) {
        if(result) {
          console.log("Sheet uploaded successfully");
          console.log(data.row_success + " rows uploaded");
        }else{
          console.log("There was some problem uploading the sheet");
        }
      }
    }
    ```

    <Note>
      Each sheet has a unique license key. Find it in the **Code** section of the sheet page and attach it to the `licenseKey` property of the `AppComponent`.
    </Note>

    ```javascript
        .csvbox-btn button {

            border-radius: 3px;
          }
      `],
    export class AppComponent {
        //...
    }
    ```

  - `18.213.249.53`

## Referencing the user

Configure **custom user attributes** in the installation code to identify the users on your platform and match them with their imports.

<Tabs>

## Callback function

Once the user uploads a file, the importer returns the status of the import along with metadata describing the completed import. Data is returned in two variables, `result` and `data`:

- **`result`**: a boolean that is `true` if the import succeeds and `false` if it fails.
- **`data`**: JSON data as shown below.

```javascript
  {
    "import_id": 79418895,
    "sheet_id": 575,
    "sheet_name": "Products Import",
    "destination_type": "webhook"
    "row_count": 100,
    "row_success": 98,
    "row_fail": 2,
    "import_status": "Partial",
    "import_starttime": 87987897897,
    "import_endtime": 90890890809,
    "original_filename": "example-1.csv",
    "raw_file": "https://file-download-link",
    "custom_fields": {
      "user_id": "Z1001"
    },
    "column_mappings": [
      { "Name": "Name" },
      { "SKU": "Product SKU" },
      { "Price": "Sale Price" },
      { "Quantity": "Inventory"},
      { "Image URL": "Img"}
    ]
  }
```

<Note>
  The `data` object is null if the import fails. You can also configure the importer to receive the entire file data in JSON format in the `data` object. [Learn more](/getting-started/3-receive-data#data-on-the-client-side).
</Note>

You can write custom code to handle the success or failure conditions on the client side.

## Options

These additional configuration options are available with the CSVbox importer.

| Option | Type | Default | What it does |
| --- | --- | --- | --- |
| <span id="max_rows" />`max_rows` | `number` | `null` | Maximum number of data rows a single file can import. Headers are not counted: a file with 101 rows whose first row is the header has 100 data rows. |
| <span id="max_rows_allow_submit" />`max_rows_allow_submit` | `boolean` | `true` | When a file has more rows than `max_rows`: if `true`, the user can submit the first `max_rows` rows; if `false`, the user can't submit any rows. |
| <span id="max_rows_custom_message" />`max_rows_custom_message` | `string` | `null` | Custom message shown when a file has more rows than `max_rows`. Shown only when `max_rows_allow_submit` is `false`. |
| <span id="min_rows" />`min_rows` | `number` | `null` | Minimum number of rows required for a single upload. |
| <span id="min_rows_custom_message" />`min_rows_custom_message` | `string` | `null` | Custom message shown when a file has fewer rows than `min_rows`. |
| <span id="language" />`language` | `string` | `null` | Importer frontend language. Overrides the default language set in the CSVbox dashboard. See [supported language codes](#supported-language-codes). |
| <span id="allow_invalid" />`allow_invalid` | `boolean` | `0` | Whether users can submit the file even if it has validation errors. |
| <span id="request_headers" />`request_headers` | `object` | `null` | Additional headers passed with each HTTP request, as `{ "Header-Name": "value" }` pairs. |
| <span id="dynamic_list_request_headers" />`dynamic_list_request_headers` | `object` | `null` | Additional headers passed with each request to the [dynamic list API](/dashboard-settings/validations#dynamic-list). |
| <span id="sample_template_url" />`sample_template_url` | `string` | `null` | URL from which end users download the sample CSV file. Use with `sample_template_button_text` to give each user a customized sample file. |
| <span id="sample_template_button_text" />`sample_template_button_text` | `string` | `null` | Text on the button that downloads the sample CSV file. |
| <span id="target_file_name" />`target_file_name` | `string` | `null` | Name of the file pushed to your destination. Applies only to the S3, FTP Server, and Google Sheets destinations. |
| <span id="upload_file_url" />`upload_file_url` | `string` | `null` | URL of a file to preload into the importer, so users don't have to upload one. The importer loads the data when the user clicks **Import**. |
| <span id="upload_file_worksheet_name" />`upload_file_worksheet_name` | `string` | `null` | Worksheet to load when the `upload_file_url` file has multiple tabs. |
| <span id="theme" />`theme` | `string` | `null` | Theme applied at runtime: `light`, `light-custom`, `dark`, or `dark-custom`. If not set, the theme from the sheet dashboard is used. |
| <span id="default_header_row" />`default_header_row` | `number` | `1` | Row auto-selected as the header on the **Header Selection** page. Rows are 1-indexed. |

## Events

These additional importer events and properties are available.

| Event | Angular name | Arguments | When it fires |
| --- | --- | --- | --- |
| <span id="onready" />`onReady` | `importerReady` | None | The importer is initialized and ready for use. Users can then click the **Import** button to open the importer modal dialog. |
| <span id="onloadstart" />`onLoadStart` | `loadStarted` | None | The importer iframe starts loading. In vanilla JavaScript, it fires only when [Lazy Load](#lazy-load) is activated; without Lazy Load, the iframe starts loading as soon as the importer is initialized. |
| <span id="onclose" />`onClose` | `closed` | None | The importer is closed. |
| <span id="onsubmit" />`onSubmit` | `submitted` | `data` (object) | The user clicks **Submit** to upload the validated file. `data` contains metadata about the import; see the [sample](#onsubmit-data-object-sample) below. |
| <span id="onimport" />`onImport` | `imported` | `result` (boolean), `data` (object) | All the data is pushed to the destination. `result` is `true` when the import succeeds and `false` when it fails; `data` contains metadata about the import. |

## Other settings

### Lazy load

The importer assets load when the webpage loads. This can slow your app if you initialize multiple importers on the same page. As a workaround, defer loading the importer assets until the **Import** button is clicked by adding the `lazy: true` parameter to the initialization code.

<Tabs>

    ```javascript
        }, callback, { lazy: true });
    ```
