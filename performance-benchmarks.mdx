These benchmarks show how long CSVbox takes to parse, validate, transform, and deliver files of 100k to 2M rows. Use them to estimate import times for your own files. Benchmarks last run: 24 August 2026.

<Note>
  One run per size, so there is no variance figure here. Treat each number as a single observation, not a median. Column count moves timing more than file size does.
</Note>

## Methodology

Each import stage is timed separately, then the whole import is timed end to end:

- **File parse**: time to read and parse the source CSV file.
- **Validation**: time to validate all rows against the target schema.
- **Transformation**: time to apply configured transforms to all rows.
- **Destination upload**: time to deliver the processed rows to the destination.
- **End to end**: total time from upload start to completed import.

## Reproducing the run

The sheet was configured with three columns typed Number, Email, and Date, and a single data-transform function applied to `col2`. The transform is intentionally trivial: one string coercion and an uppercase. This way, the transform timings measure the pipeline's per-row dispatch overhead, not the cost of a user's own logic.

### Data transform function

This is the exact function, applied to `col2`, that produced the transformation numbers above.

```js
const helper = (value) => {
  return String(value).toUpperCase();
};
csvbox.row["col2"] = helper(csvbox.row["col2"]);
return csvbox;
```
