CSVbox gives your web app a production-ready import feature in just a few minutes. Your users upload spreadsheets through an embeddable importer, and CSVbox validates the data and pushes it to the destination you choose.

## Key concepts

These terms are used throughout the application:

| Term | Definition |
| --- | --- |
| **User** | Any person who uses your application. |
| **File** | The spreadsheet file that the users want to upload to your application. Users can upload `.csv`, `.xlsx`, or `.xls` files. |
| **Sheet (template)** | The data model that specifies the structure of the data you want to accept. You add columns to the sheet and configure validation criteria in your CSVbox dashboard. Users match the headers of their file columns with the sheet columns and clean the data before uploading. |
| **Import** | The entire process where the user opens the CSVbox importer to select the file, match columns, validate data, and submit the file. |
| **Destination** | The end location where the CSVbox importer pushes the data uploaded by the user. |
