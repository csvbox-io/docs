<Update label="October 2026" description="Google Cloud Storage destination, Security update, Checkbox display for Boolean columns, Sheet Tags, smart date and number formats, If / Else Builder">
  ### Google Cloud Storage destination

  **Added**: [Google Cloud Storage](/destinations/google-cloud-storage) as a data destination. Send every import to a bucket in your own Google Cloud Storage as a single CSV or JSON file. Connect with a service account JSON key, choose a bucket, optional folder path and file name, and use **Test Connection** to confirm access before saving.

  ### Security update: PHP dependency vulnerability fixed

  **October 22, 2026 · 10:00 AM IST**

  We've fixed a security vulnerability in the PHP framework and libraries that run the CSVBox platform. We updated the affected components to patched versions and deployed them across the platform.

  - **No action needed.** Your importers, API keys, and destination settings are unchanged and keep working as before.
  - **No impact found.** We found no sign that this vulnerability was exploited.

  If you have questions about this update, contact us at [info@csvbox.io](mailto:info@csvbox.io).

  ### Checkbox display for Boolean columns

  **Added**: [Display as checkbox](/dashboard-settings/validations#display-as-checkbox) for Boolean columns. Turn on **Display as checkbox** for a Boolean column to show a checkbox in each cell on the Verify Data screen. Every value is converted to `true` or `false` before it is sent to your destination, so the column never shows a validation error. Also available in the Sheet API as `render_as_checkbox`.

  ### Sheet Tags

  **Added**: [Sheet Tags](/dashboard-settings/sheet-tags). Attach color-coded tags to your sheets to group them, and filter the Sheets page by one or more tags. Add tags with **\+ Tag** on any sheet, and manage them from the **Tags** page. Tags are kept per account and are not copied when a sheet is copied to another team or account.

  ### Smart date and number formats

  **Added**: [Smart Date and Number Formats](/dashboard-settings/smart-date-and-number-formats). CSVbox now converts dates and numbers written in different regional formats into the format your column expects, and asks the user once when a value such as `04/05/2024` or `1,234` could be read two ways. Turn it on with **Date correction?** under **Import Steps** → **Verify Data**.

  ### If / Else Builder

  **Added**: [If / Else Builder](/advanced-installation/if-else-builder). Build Validation Functions and Data Transforms visually with IF / ELSE IF / ELSE rules, without writing JavaScript.
</Update>

<Update label="September 2026" description="MCP server, importer GET APIs, and 11 new column types">
  ### MCP server

  **Added**: CSVbox now ships an MCP server. Configure importers by prompting Claude, Cursor, or any MCP client instead of hand-writing schema JSON.

  ### Importer GET APIs

  **Added**: GET APIs to retrieve a list of importers and view the complete configuration of a specific importer, with sensitive credentials excluded.

  ### 11 new column types

  **Added**: 11 new column types give you more options for validating and normalizing imported data, including **Percentage, IANA Timezone, UPC, EAN, UUID, Domain, Currency Code, Country Code A2, Country Code A3, IMEI, and JSON**.
</Update>

<Update label="August 2026" description="2M-row files, review table enhancements, AI sheet generation, and more">
  ### Files with up to 2M rows

  **Added**: CSVbox can now handle files with **up to 2M rows**, making it easier to import and process high-volume datasets without splitting them into smaller batches.

  ### Spreadsheet review table enhancements

  **Added**: Column sorting (3-state cycle with numeric-aware ordering), advanced filtering (value/condition operators with multi-column logic), right-click context menus for cells/columns/rows, and full undo/redo support (up to 50 steps).

  ### Sorting in the upload table

  **Added**: Sorting support in the upload table. Table rendering was reworked to handle sorted views correctly.

  ### AI sheet generation

  **Added**: A new AI-powered feature that lets you **generate a CSVbox sheet and define its columns** simply by describing your requirements.

  ### Column logic via Sheet API

  **Added**: Create, update, and manage Validation Functions, Virtual Columns, and Data Transforms via the Sheet API.
</Update>

<Update label="June 2026" description="Neon, OpenAPI, and Xero destinations, Sheets API, and new automation integrations">
  ### Neon destination

  **Added**: [Neon](https://neon.tech) as a data destination. Push imported data directly to Neon serverless Postgres databases, with built-in credentials management and connection handling.

  ### OpenAPI destination

  **Added**: [OpenAPI](/destinations/openapi) specification support as an upload destination type. Point CSVbox to an OpenAPI/Swagger spec URL and it automatically routes import data to your API endpoints.

  ### Secret key for Sheet API authorization

  **Added**: Secret key + API key combination for Sheet API authorization, adding an extra layer of security for embedding and API access.

  ### REST API auto mapping priority

  **Improved**: REST API `auto_map` now matches columns using the same priority order as the frontend importer: `display_label` first, then `column_name`, then matching keywords.

  ### Make, Pabbly, and IFTTT integrations

  **Added**:

  - CSVbox as an in-app integration in [Make](https://make.com).
  - CSVbox as an app in [Pabbly](https://www.pabbly.com).
  - CSVbox as an app in [IFTTT](https://ifttt.com).

  ### Xero destination

  **Added**: [Xero](https://www.xero.com/) as a data destination. Automatically push imported data to Xero with secure authentication and simplified connection setup.

  ### Sheets API

  **New**: [Sheets API](/advanced-installation/sheet-api). You can now create and manage importer sheets programmatically instead of only through the dashboard.
</Update>

<Update label="May 2026" description="AI Function Generator, split large CSV imports, and AI document import">
  ### AI Function Generator

  **New**: [AI Function Generator](/dashboard-settings/ai-function-generator). Generate validation functions, virtual columns, data transforms, and regex patterns using plain-language prompts. Describe what you want, and CSVbox generates compatible JavaScript or regex logic automatically.

  ### Split large CSV file imports

  **New**: [Split Large CSV File Imports](/dashboard-settings/split-large-csv). CSVbox can now automatically split large CSV files into smaller parts during import for improved reliability and browser performance. Multipart uploads reuse the same column mappings across all parts and are grouped together in the Imports dashboard for easier tracking.

  ### AI document import

  **New**: [AI Document Import](/dashboard-settings/ai-document-import) (PDFs, Images & DOCX). You can now import data from PDFs, images, and documents using AI-powered table extraction.
</Update>
