The Bubble.io destination pushes the CSV and Excel files your users upload directly into your Bubble app database. You configure the Bubble Data API, connect it to a CSVbox sheet, and add the CSVbox plugin to your app.

## Demo app

See how it works [here](https://csvbox-demo.bubbleapps.io/version-test).

## Configuring Bubble app

<Note>
  You need to be on a [paid Bubble application plan](https://bubble.io/pricing/compare) to use the Bubble API, which is required to push external CSV data into the Bubble data store.
</Note>

## Setting up CSVbox

<Steps>
  <Step title="Log in to CSVbox">
    Log in to [csvbox.io](https://app.csvbox.io/login).
  </Step>
  <Step title="Add a sheet">
    <Frame>
      <img
        src="/images/add-sheet.png"
        alt="Add a sheet"
      />
    </Frame>
  </Step>
  <Step title="Add columns">
    Add columns to the sheet. The column names should match the column/object names for your data type in Bubble. Pay attention to upper and lower case letters in Bubble and match them in CSVbox.

    <Frame>
      <img
        src="/images/add-columns.png"
        alt="Add columns"
      />
    </Frame>
  </Step>
  <Step title="Select Bubble.io as the destination">
    Under the **Settings** section, for the **Send Data To** setting, select **Bubble.io**.

    <Frame>
      <img
        src="/images/bubble-io-settings.jpg"
        alt="Bubble.io data destination settings"
      />
    </Frame>

    Fill in the following fields:

    - **App Name**: the name of your Bubble.io app.
    - **Custom Domain Name**: if you have attached a custom domain name to your Bubble app, provide it here.
    - **Environment**: pick the environment where you want the CSV data to be sent, either TEST/DEVELOPMENT or PRODUCTION/LIVE.
    - **API Private Key**: the API token you generated while configuring the [API settings](/destinations/bubble-io#api-settings) in the Bubble app.
    - **Data Type**: the data type name where you want to push the CSV data.
  </Step>
  <Step title="Test the connection">
    Click **Test Connection**. It succeeds if all fields are filled in correctly.
  </Step>
  <Step title="Map columns">
    Click **Map Columns**. A modal opens where you can map the sheet columns to the object fields.

    <Frame>
      <img
        src="/images/map-columns-2.jpg"
        alt="Map sheet columns to Bubble data fields"
      />
    </Frame>

    <Warning>
      The data fields from the Bubble database are available in the Map Column modal only if they have data in the first row. Add dummy data for each data field in the first row so that they appear in the Map Column modal.
    </Warning>
  </Step>
  <Step title="Save the sheet">
    Click **Save**.
  </Step>
  <Step title="Copy the Sheet License Key">
    Go to the **Code** section of the sheet and note down the **Sheet License Key**.

    <Frame>
      <img
        src="/images/sheet-license-key.png"
        alt="Sheet License Key"
      />
    </Frame>
  </Step>
</Steps>

## Adding CSVbox to Bubble

<Steps>
  <Step title="Install the plugin">
    Install the [csvbox.io](https://bubble.io/plugin/csv--excel-importer-|-receive-json-1628686647935x372170116910546940) plugin in your Bubble app.
  </Step>
  <Step title="Add the CSVBox Button element">
    Drag the CSVBox Button element onto your web page.
  </Step>
  <Step title="Set the Sheet License Key">
    Paste the **Sheet License Key** value from the sheet **Code** page (saved above) into the **Sheet License Key** property of the CSVBox element.

    <Frame>
      <img
        src="/images/bubble-app-csvbox-element.png"
        alt="Bubble app CSVBox Button element"
      />
    </Frame>
  </Step>
  <Step title="Configure the button">
    Enter the import button label in the `button_text` property. Optionally, add CSS classes in the `button_classes` property to style the CSVbox import button.

    <Note>
      You can add custom user attributes (such as user_id, user name, company name, etc.) as values to the `custom_attribute_XX` properties of the CSVBox Button element. More information on custom attributes is available [here](/getting-started/2-install-code#referencing-the-user).
    </Note>
  </Step>
</Steps>

The CSVbox import button is now available in your app. Your users can click the button to upload CSV files, and the data arrives in your Bubble database.

### Import events

The CSVBox Button element exposes two events that indicate the completion of the import process:

- **import_success**: triggered when the CSV data is imported successfully into your Bubble database.
- **import_fail**: triggered when the import failed completely or partially.

<Frame>
  <img
    src="/images/bubble-events.png"
    alt="CSVBox Button element events"
  />
</Frame>

You can add relevant actions to process the import result events.

## Why does my upload fail with unknown errors?

Bubble.io databases are very picky. The column names you POST from the CSVbox importer must **exactly** match what is in your Bubble.io database.

Check the following:

- Make sure there are no extra columns in your CSVbox sheet that do not map to a field/attribute in your Bubble.io database object. Bubble does not accept extra columns that its database doesn't know about.
- The CSVbox sheet column names must **exactly** match the type names in your Bubble.io database object. Verify that capitalization and spaces are exactly the same as in your Bubble.io data type object.
- In your Bubble.io app settings, click **API** and make sure all checkboxes are checked for exposing the Data API, and for every database object you want to import into.

<Note>
  The maximum number of items that can be created in Bubble.io via a single bulk request is currently 1000.
</Note>
