title: "Supabase"

---

The Supabase destination pushes uploaded spreadsheet data from CSVbox straight into your Supabase database. It's ideal for SaaS products that already use Supabase as their backend.

## Set up the destination

<Steps>
  <Step title="Choose Supabase as the destination">
    In your **Sheet Settings**, set **Destination Type** to **Supabase**.
  </Step>
  <Step title="Connect your database">
    Provide your Supabase project credentials:

    - **Project URL**: found in your Supabase project settings.
    - **Service Role Key**: available under **Project → API → Service Role**.

    <Note>
      CSVbox stores credentials securely and uses them only for insert operations.
    </Note>
  </Step>
  <Step title="Set the target table name">
    Enter the **Table Name** where you want the imported data to be inserted. The table must already exist in your Supabase database.

    Click **Test Connection** to confirm that the connection is successful.
  </Step>
  <Step title="Map columns to fields">
    Match each column in your CSV or Excel sheet to the corresponding field in your Supabase table.
  </Step>
  <Step title="Map custom attributes (optional)">
    You can also map custom attributes from the CSV to specific fields in your table.
  </Step>
</Steps>

## Data flow

Once setup is complete, every submitted file automatically inserts the processed data into your Supabase table, row by row, without any manual intervention.

## Notes

* Your Supabase table schema must match the uploaded columns. Column names are case-sensitive.
* Insert operations use Supabase's REST API under the hood.
* Bulk uploads are optimized for large CSV files.
* You can combine Supabase with CSVbox features like **validation rules**, **virtual columns**, and **AI transforms** for advanced workflows.
