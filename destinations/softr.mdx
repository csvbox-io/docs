CSVbox sends imported spreadsheet data directly into **Softr Databases**, enabling no-code workflows such as internal tools, portals, directories, and dashboards powered by Softr.

With this destination, every successful CSV import inserts rows into a selected Softr table.

## When to use Softr as a destination

Use the **Softr** destination when you want to:

* Import CSV / Excel data into Softr databases
* Power Softr apps with bulk uploads
* Allow non-technical users to upload structured data
* Replace manual Softr data entry with a guided importer

## Configure Softr destination in CSVbox

Follow the steps below to configure Softr as your data destination.

<Steps>
  <Step title="Select Softr as the destination">
    Go to **Sheet Settings** → **Destination**, click **Select Destination**, and choose **Softr** from the list.
  </Step>
  <Step title="Enter your Softr credentials">
    Fill in the following required fields:

    - **API Key**: your Softr API Key, used to authenticate requests from CSVbox to Softr.
    - **Database ID**: the ID of the Softr database where data should be inserted. This identifies the parent database inside Softr.
    - **Table ID**: the specific table inside the database that receives the data. Each imported row becomes a new record in this table.

    <Tip>
      To get the Database ID and Table ID from Softr:

      1. Log in to Softr.
      2. Go to **Data** → **Databases**.
      3. Click the **database** you want.
      4. Click the **table** inside that database.
      5. Look at the **browser URL**.

      You'll see something like `https://studio.softr.io/databases/ecc84771-ca85-48f2-abc3?table=ajZqlE5O9KOy1`. Extract the IDs:

      - **Database ID**: `ecc84771-ca85-48f2-abc3`
      - **Table ID**: `ajZqlE5O9KOy1`
    </Tip>
  </Step>
  <Step title="Test the connection">
    Click **Test Connection** to verify:

    - API key validity
    - Access to the specified database
    - Access to the selected table

    A successful test confirms CSVbox can write data to Softr.
  </Step>
  <Step title="Map columns">
    Click **Map Columns** to:

    - Map CSV / Excel columns to Softr table fields
    - Ensure field types are compatible
    - Control which columns are sent to Softr

    <Note>
      Column mapping is mandatory before running an import.
    </Note>
  </Step>
  <Step title="Save the configuration">
    Click **Save** to persist the Softr destination settings. Your importer is now ready to send data directly into Softr.
  </Step>
</Steps>

## How data is sent to Softr

* Each successfully imported row becomes **one record** in the selected Softr table.
* Data is sent **after validation** and **after transforms**.

## Troubleshooting

**Connection test fails**

* Verify API key permissions.
* Double-check the Database ID and Table ID.
* Ensure the table exists and is accessible.

**Columns not appearing**

* Revisit **Map Columns**.
* Ensure Softr field names and types match the incoming data.

## Notes & limitations

* The Softr destination currently supports **row inserts**.
* Large imports may take longer depending on Softr API limits.
