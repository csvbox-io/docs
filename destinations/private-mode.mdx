---
title: "Private Mode"
description: "Keep user data off CSVbox servers and data stores by processing imports entirely in the client browser."
---

CSVbox offers three configurations for handling user data. Choose the one that matches your privacy and retention requirements.

|  | Standard | No Store | Private |
| --- | --- | --- | --- |
| **Data processing** | Client browser, CSVbox server | Client browser, CSVbox server | Client browser |
| **Data storage** | CSVbox datastore | - | - |

## Standard mode

<Frame caption="Standard Mode"><img src="/images/standard-mode-flow.svg" alt="Standard Mode: files go from the browser to CSVbox servers, which push data to your system and store a copy in the CSVbox datastore" /></Frame>

This is the default configuration. User data is encrypted in transit and at rest. The data is pushed to your system, and a copy of it is stored in the CSVbox database.

The copy is auto-deleted after one month. Your system can access the data from the CSVbox datastore any time during this month. Optionally, the data is also available in the client browser.

## No store mode

<Frame caption="No Store Mode"><img src="/images/no-store-mode.svg" alt="No Store Mode" /></Frame>

In this mode, the user data isn't stored in the CSVbox database. It's pushed directly to your system. Optionally, the data is also available in the client browser.

<Warning>

Metadata that describes the import is stored in CSVbox. This includes data such as Import ID, Import Start Time, End Time, Sheet ID, etc.

</Warning>

To activate this mode, go to your CSVbox dashboard → **Edit Sheet** → **Security** tab, and for **File Delete Policy** select **Do not store the file**.

<Frame>
  <img
    src="/images/do-not-store.jpg"
    alt="File Delete Policy set to Do not store the file"
  />
</Frame>

## Private mode

<Frame caption="Private Mode"><img src="/images/private-mode.svg" alt="Private Mode" /></Frame>

In Private Mode, the user data doesn't transit CSVbox servers and isn't stored in our databases. The data is processed in the client browser and is available for consumption there. You can then push the data to your system by implementing custom code.

<Warning>

Metadata that describes the import is stored in CSVbox. This includes data such as Import ID, Import Start Time, End Time, Sheet ID, etc.

</Warning>

To activate Private Mode:

<Steps>
  <Step title="Turn off file storage">
    Go to your CSVbox dashboard → **Edit Sheet** → **Security** tab, and for **File Delete Policy** select **Do not store the file**.

    <Frame>
      <img
        src="/images/do-not-store.jpg"
        alt="File Delete Policy set to Do not store the file"
      />
    </Frame>
  </Step>
  <Step title="Clear the destination">
    Go to Sheet **Settings** → **Destination** tab and select **--** for the **Send Data To** option.
  </Step>
  <Step title="Send a copy of the data to the client">
    Select **Yes** for the **Send a copy of data to client?** option.

    <Frame>
      <img
        src="/images/sheetsettings.jpg"
        alt="Send a copy of data to client setting"
      />
    </Frame>
  </Step>
</Steps>

The user data is available at the client in the format shown [here](/getting-started/3-receive-data#data-on-the-client-side).
