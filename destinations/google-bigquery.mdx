---
title: "Google BigQuery"
description: "Import CSV or Excel data directly into your Google BigQuery tables using CSVbox."
---

The Google BigQuery destination inserts the data your users upload into an existing BigQuery table. Follow the steps below to securely connect your BigQuery project and map your columns.

## Set up the destination

<Steps>
  <Step title="Choose Google BigQuery as the destination">
    On your sheet's **Destination Settings** page, select **Google BigQuery** from the **Send Data To** dropdown. This enables all the fields needed to configure your BigQuery connection.
  </Step>
  <Step title="Enter the connection details">
    Fill in the following fields:

    - **Project ID**: your Google Cloud Project ID. You can find this in your Google Cloud Console under **Home** → **Project Info** → **Project ID**.
    - **Dataset ID**: the dataset where your target table is located. This is the dataset name within your BigQuery project.
    - **Table Name**: the exact name of the table where the data should be inserted. Make sure this table already exists in your BigQuery dataset.
  </Step>
  <Step title="Upload the JSON key file">
    BigQuery requires authentication via a **Service Account Key**.

    1. In your Google Cloud Console, go to **IAM & Admin** → **Service Accounts** → **Keys** → **Add Key** → **Create New Key**.
    2. Choose **JSON** as the key type and download the file.
    3. In CSVbox, click **Browse**, select your JSON key file, and click **Upload**.

    <Warning>
      Only `.json` files are accepted for this field.
    </Warning>

    This securely connects CSVbox to your BigQuery project.
  </Step>
  <Step title="Test the connection">
    After entering your credentials, click **Test Connection**. CSVbox attempts to connect to your BigQuery project and validates the configuration.

    - If it succeeds, you see a confirmation message.
    - If there's an error, double-check your credentials, dataset, or table name.
  </Step>
  <Step title="Map columns">
    Once your connection is validated, click **Map Columns** and map the columns from your CSV file to the corresponding fields in your BigQuery table.
  </Step>
</Steps>

After mapping, all future imports through your CSVbox importer automatically push data into your specified BigQuery table.

## Notes

* Ensure that the BigQuery table schema matches the data types in your uploaded CSV to avoid type mismatch errors.
* CSVbox uses the **Service Account credentials** only to insert data. No other operations are performed.

## Example configuration

| Field | Example value |
| --- | --- |
| Project ID    | `data-project-123`          |
| Dataset ID    | `sales_data`                |
| Table Name    | `orders`                    |
| JSON Key File | `bigquery-credentials.json` |

## Troubleshooting

* **Invalid JSON key**: ensure the key file is not modified and is a valid service account key.
* **Table not found**: confirm that the specified table exists in the dataset.
* **Permission denied**: verify that your service account has the `BigQuery Data Editor` role or higher.
