On the Verify Data step, users review their data, fix errors, and submit. Validation rules you set on [Columns](/sheet-settings/columns) are checked here.

## Export button

Let users export their data, with errors highlighted, to Excel.

Enable or disable the **Export** button on the Verify Data screen. The exported Excel file keeps the error highlighting and error messages, so users can fix the errors in Excel and quickly re-upload the file to CSVbox.

## Other Verify Data settings

These features are configured under **Import Steps** → **Verify Data**:

- **Date correction**: convert dates and numbers written in different regional formats, and ask users only when a value is unclear. See [Smart Date and Number Formats](/dashboard-settings/smart-date-and-number-formats).
- **AI Bulk Transforms**: let users modify column data with natural language prompts. See [AI Bulk Transforms](/dashboard-settings/ai-bulk-transforms).
