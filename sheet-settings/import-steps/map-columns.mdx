---
title: "Map Columns"
description: "Control how users match file columns to template fields, and whether they can submit unmapped columns or ignore columns."
---

On the Map Columns step, users match the columns in their file to the columns in your sheet. These settings control the direction of the mapping and what happens to columns that don't match. To set up the template columns themselves, see [Columns](/sheet-settings/columns).

## Mapping choice

Let users map file columns to template fields, or template fields to file columns.

By default, on the column mapping screen, **Template Fields** are fixed on the left and **Uploaded File Columns** appear on the right in a dropdown, so users map each file column to a template field.

The **Mapping Choice** option reverses this direction. Selecting **Template Fields** as the Mapping Choice flips the layout: **File Columns** are fixed on the left, and **Template Fields** appear in the dropdown on the right. This suits different file structures and user preferences.

<Warning>
  The **Template Fields** Mapping Choice is **not compatible** with the [Ignored columns](#ignored-columns) functionality.
</Warning>

## Zero template columns

Accept file submissions without any predefined template columns.

By default, CSVbox requires at least one template column for mapping. Setting **Allow Zero Template Columns** to **Yes** lets users submit files **without any predefined template columns**. Combine it with [Unmapped columns](#unmapped-columns) so users can upload files with **any set of columns**.

<Frame>
  <img
    src="/images/sleekshot-5.png"
    alt="Allow Zero Template Columns setting"
  />
</Frame>

Use it when you want to accept user-defined file formats as they are, without enforcing a rigid template.

<Note>
  For this feature to work effectively, set **Allow Unmapped Columns** to **Yes** along with the **Show Unmapped Columns on Validation Screen** selection. This lets users review and verify file columns before submission.
</Note>

## Unmapped columns

Sometimes each of your users has unique columns in their sheets that they want to upload. You don't know these columns beforehand, so you can't configure them as part of the sheet template. They can be discovered only after the user uploads the file, so you can't configure them as [dynamic columns](/advanced-installation/dynamic-columns#basic-installation) either. CSVbox calls these columns **Unmapped Columns**, and you can choose to accept them.

### Enable unmapped columns

Start accepting data from unmapped columns by activating the option in your CSVbox dashboard.

<Steps>
  <Step title="Log in to your account">
    Sign in to the CSVbox dashboard.
  </Step>
  <Step title="Edit the sheet">
    Open the sheet of your choice for editing.
  </Step>
  <Step title="Open the Options tab">
    Go to the **Options** tab.
  </Step>
  <Step title="Accept unmapped columns">
    Select **Yes** for the **Accept Unmapped Columns?** field.
  </Step>
  <Step title="Save the sheet">
    Click **Save**.
  </Step>
</Steps>

The importer then starts accepting data from the unmapped columns that users submit.

### Receive data from unmapped columns

Data from unmapped columns is available in the data destinations along with the data from the regular columns. Currently, unmapped columns are supported only by the following destinations:

- [API/Webhook](/destinations#api--webhook)
- [Amazon S3](/destinations#amazon-s3)

#### API/Webhook data destination

In the API response JSON object, the dynamic data appears inside the `_unmapped_data` object, as shown below. The `_unmapped_data` object is visible only if unmapped columns are activated.

```json
[
  {
    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 1,
    "row_data": {
      "Name": "TP-Link TL-WN822N Wireless N300 High Gain USB Adapter",
      "SKU": "AS-100221",
      "Price": "33.00",
      "Quantity": "3",
      "_unmapped_data": {
        "Barcode": "7832748937489",
        "_empty_header_1": "TP-Link",
        "Tags": "electronics, networking"
      }
    },
    "custom_fields": {
      "user_id": "1002"
    }
  },
  {
    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 2,
    "row_data": {
      "Name": "EPower Technology EP-600PM Power Supply 600W ATX12V 2.3 Single 120mm Cooling Fan Bare",
      "SKU": "AS-103824",
      "Price": "95.35",
      "Quantity": "8",
      "_unmapped_data": {
        "Barcode": "4532748937411",
        "_empty_header_1": "EPower",
        "Tags": ""
      }
    },
    "custom_fields": {
      "user_id": "1002"
    }
  }
]
```

<Note>
  If any unmapped column has no header in the user's uploaded file, the app auto-inserts the column names `_empty_header_1`, `_empty_header_2`, and so on.
</Note>

#### S3 data destination

In the AWS S3 file store, unmapped columns are added as new columns in the uploaded file.

## Ignored columns

Users sometimes want to skip a column during data submission. This is especially useful when you use the importer to update existing data: to avoid overwriting existing columns, users can mark those columns as **Ignored** and the importer skips them. With CSVbox, you can give users the option to mark certain columns as ignored.

### Enable ignored columns

First, activate the Ignore Columns option in your CSVbox dashboard.

<Steps>
  <Step title="Log in to your account">
    Sign in to the CSVbox dashboard.
  </Step>
  <Step title="Edit the sheet">
    Open the sheet of your choice for editing.
  </Step>
  <Step title="Open the Options tab">
    Go to the **Options** tab.
  </Step>
  <Step title="Allow columns to be ignored">
    Select **Yes** for the **Allow Columns to be Ignored** field.
  </Step>
  <Step title="Save the sheet">
    Click **Save**.
  </Step>
</Steps>

The importer then shows the option to mark columns as ignored on the Column Mapping screen.

Columns marked as ignored aren't visible on the Verify Data screen.

<Note>
  The Ignore Column option isn't available for columns marked as **Required**.
</Note>

### Default selection

When the **Default Selection** option is set to **Yes**, all unmapped columns default to Ignore Column.

### Data from ignored columns

Ignored columns aren't pushed to any destination. Only the metadata (the list of ignored columns) is pushed to the following destinations:

- [API/Webhook](/destinations#api--webhook)
- [Zapier](/destinations/zapier)
- [Client Side](/getting-started/3-receive-data#data-on-the-client-side)

#### Ignored column list

In the API response JSON object, the list of ignored columns appears inside the `ignored_columns` object, as shown below. The `ignored_columns` object is visible only if ignored columns are activated.

```json
[
  {
    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 1,
    "row_data": {
      "Name": "TP-Link TL-WN822N Wireless N300 High Gain USB Adapter",
      "SKU": "AS-100221",
      "Price": "33.00",
      "Quantity": "3"
    },
    "custom_fields": {
      "user_id": "1002"
    },
    "ignored_columns": ["qualification", "experience"]
  },
  {
    "import_id": 79418895,
    "sheet_id": 55,
    "sheet_name": "Products",
    "row_number": 2,
    "row_data": {
      "Name": "EPower Technology EP-600PM Power Supply 600W ATX12V 2.3 Single 120mm Cooling Fan Bare",
      "SKU": "AS-103824",
      "Price": "95.35",
      "Quantity": "8",
      "_ignored_data": {
        "qualification": "MA",
        "experience": "6"
      }
    },
    "custom_fields": {
      "user_id": "1002"
    },
    "ignored_columns": ["qualification", "experience"]
  }
]
```
