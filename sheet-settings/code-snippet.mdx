---
title: "Code Snippet"
description: "Find the integration code for a sheet and the license key that ties the importer to it."
---

Every sheet has an integration code snippet that embeds the CSVbox importer in your app. Open the sheet and go to its **Code** tab to find it. Place the snippet in your application where you want the import button to appear.

The snippet is available for JavaScript, React, Angular, and Vue.js.

<Note>
  Each sheet has a unique license key. Find it on the **Code** tab of the sheet and pass it to the importer when you initialize it.
</Note>

For full installation instructions, including referencing the user, the callback function, options, and events, see [Install the Code](/getting-started/2-install-code).

If your app or database restricts access to an IP allowlist, see the [allowlist warning](/getting-started/2-install-code#install-the-importer) before going live.
