A destination is where the importer pushes the data your users upload. You choose it per sheet in the sheet settings, and CSVbox delivers every validated import there automatically.

<Note>
  Only one destination can be selected per sheet at a time.
</Note>

Each destination has a full setup guide on its own page. The sections below summarize the destinations that are built into the sheet settings.

## None

The user-uploaded data isn't pushed anywhere. The files are, however, available for download via the CSVbox admin. More information [here](/destinations/none).

## Test API

A lightweight destination that posts every successful import to a unique `webhooks.csvbox.io` URL, so you can validate your setup before wiring up your own backend. For initial testing only. More information [here](/destinations/test-api).

## API / Webhook

Push the data to a webhook endpoint of your own as JSON, XML, or FORM Data, in chunks of rows. More information [here](/destinations/api-webhook).

## Amazon S3

Push the files your users upload to the AWS S3 bucket of your choice, in CSV or JSON format. More information [here](/destinations/amazon-s3).

## FTP Server

Push the files your users upload to your FTP server. More information [here](/destinations/ftp-server).

## MySQL

Import CSV files and Excel sheets directly into your MySQL tables. More information [here](/destinations/mysql).

## PostgreSQL

Import CSV files and Excel sheets directly into your PostgreSQL tables. More information [here](/destinations/postgresql).

## SQL Server

Import CSV files and Excel sheets directly into your SQL Server tables, with Insert and Upsert operations. More information [here](/destinations/sql-server).

## MongoDB

Import CSV files or Excel sheets into your MongoDB collections. More information [here](/destinations/mongodb).

## Google Sheets

Import CSV files and Excel sheets directly into Google Sheets. More information [here](/destinations/google-sheets).

<a id="2-upsert" />

## Airtable

Import CSV files and Excel sheets directly into your Airtable tables, with Insert and Upsert operations. More information [here](/destinations/airtable).

## Bubble

Import user CSV files and Excel sheets directly into your Bubble app. More information [here](/destinations/bubble-io).

## Notion

Import user CSV files and Excel sheets directly into your Notion databases. More information [here](/destinations/notion).

## Zapier

Import user CSV files and Excel sheets to Zapier. More information [here](/destinations/zapier).

## Webflow

Import user CSV files and Excel sheets to Webflow. More information [here](/destinations/webflow).

## Xano

Send your users' CSV and Excel data to a Xano API endpoint, using your API group's Swagger spec to map columns to the endpoint's input fields. More information [here](/destinations/xano).

## Xero

Import user CSV files and Excel sheets into your Xero organisation, including contacts, invoices, payments, and bank transactions. More information [here](/destinations/xero).
